# Market preset: USA 🇺🇸  (ATS-optimised)

**Header:** Name + contact line (phone | email | LinkedIn | city, state). **No photo.**

**Do NOT include:** photo, date of birth, age, marital status, nationality, a
headshot, or personal details — these can create discrimination-law problems and
break ATS parsing.

**Length:** **1 page** for early career (strict); 2 pages only for 10+ yrs experience.

**ATS rules:** single column, standard section names (Summary, Experience,
Education, Skills), no text in headers/footers, no tables for content, no graphics.
Use standard fonts. Mirror keywords from the job description.

**Tone / bullets:** strong action verbs + quantified impact (%, $, time). US spelling
(optimize, organize). Lead each bullet with the result where possible.

**Section order:** Summary → Experience → Education → Technical Skills → (Awards).

**Engine notes:** use `engine/prism-base.tex` as-is (it is already single-column,
ATS-friendly). No photo block. Trim aggressively to fit one page.
