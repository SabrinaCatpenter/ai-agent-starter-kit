I took beautiful notes all semester — and reopened almost none of them before exams.

The problem was never the notes.

It was the effort of turning them into revision. That felt like a chore, so I kept
putting it off until it was too late to matter.

So instead of another productivity system I'd abandon, I built one small AI skill.

I drop a lecture note into a folder. My agent hands back a summary, six flashcards,
and a five-question quiz. Tuned to my subject, in my style. About two hours to set up.

First week: I revised four lectures I'd normally have skipped.

Not because I found new willpower — because "drop a file in a folder" is easy enough
to do on a tired evening.

The lesson stuck with me: you don't need an AI that runs your life. You need one
skill that removes one bit of friction from one thing you keep avoiding.

What's the one task you keep putting off that a tiny automation could make easy?
