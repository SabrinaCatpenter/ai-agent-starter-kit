# Source (worked example)

## Topic / working title
How I built a personal "study agent" that turns my lecture notes into revision

## Audience
University students who feel behind on revision

## Goal
Teach something (and quietly show it's doable)

## Tone
Friendly, honest

## Key points / raw notes
- I took good notes all semester but never reopened them before exams
- Built a small AI "skill": drop a lecture note in a folder, it returns a summary,
  6 flashcards, and a 5-question quiz
- It's tuned to my subject and my style — not a generic chatbot
- Took ~2 hours to set up in a starter kit; runs inside my coding agent
- First week using it: I revised 4 lectures I'd normally have skipped
- The point isn't the tool — it's that revision became low-effort enough to actually happen

## Call to action
Try building one small skill of your own this week
