# I stopped rereading my notes. I built a study agent instead.

*TL;DR: I made a tiny AI skill that turns each lecture note into a summary, six
flashcards, and a short quiz. It didn't make me smarter — it made revising so easy
that I finally did it.*

I took beautiful notes all semester. Colour-coded, well organised, genuinely good.

And I reopened almost none of them before exams.

The problem was never the notes. It was the activation energy: turning a folder of
notes into actual revision felt like a chore, so I kept putting it off until it was
too late to matter.

## The small thing I built

Instead of a productivity system I'd abandon in a week, I built one small AI skill.

Here's the whole thing: I drop a lecture note into a folder, and my agent gives me
back three things — a short summary, six flashcards, and a five-question quiz.

That's it. No new app. It runs inside the coding agent I already use, and it took me
about two hours to set up from a starter kit.

## Why it actually worked

Two reasons it stuck where other tools didn't:

**It's tuned to me.** It knows my subject and the way I write, so the flashcards
sound like my course — not like a generic chatbot guessing.

**It lowered the effort past my laziness threshold.** In the first week I revised four
lectures I would normally have skipped entirely. Not because I found new willpower —
because "drop a file in a folder" is easy enough to do on a tired evening.

## The real takeaway

The point isn't this particular tool. It's that a small, personal automation can turn
a task you avoid into one you actually do.

You don't need to build an assistant that runs your life. You need one skill that
removes one bit of friction from one thing you keep avoiding.

If you're a student staring at a semester of unread notes: pick one small skill and
build it this week. Start with the thing you avoid most.
